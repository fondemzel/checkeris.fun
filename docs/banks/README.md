# Банки и маркетплейсы

Откуда траты приходят сами: вход в банки, синхронизация операций, чеки Озона и Wildberries, Android-приложение, которое всё это делает на телефоне.

## Границы

**Сюда:** Т-Банк, Сбер, Озон, WB — вход, сессии, тихий вход, повтор запросов веб-версии; загрузка истории; счета; сопоставление операций с чеками, переводы между своими счетами; фоновые задачи и разрешения Android; сборка и выпуск APK.

**Не сюда:** как операции выглядят на экранах (→ [app](../app/README.md)), категории операций по правилам (→ [data](../data/README.md)).

## Код

| Путь | Что |
|---|---|
| `client/android/` | Android-приложение: вход в банки (`BankLoginActivity`, `TBank*`, `Sber*`, `Ozon*`, `Wb*`), фон (`BankJobService`), мост к странице (`MainActivity`), разрешения, копии |
| `api/src/banks.mjs`, `bankhistory.mjs`, `bankaccounts.mjs`, `bankformat.mjs` | приём операций, история, счета |
| `api/src/bankmatch.mjs`, `prepaid.mjs`, `fx.mjs` | сопоставление с чеками, переводы, валюта |
| `api/src/shops.mjs`, `ozonpdf.mjs`, `wbreceipt.mjs` | маркетплейсы |
| `scripts/build_apk.sh` | сборка APK (`--release "что нового"`, `--install`) |

## Важное

- **Пароли и ПИН-коды банков не хранить никогда.** Только повтор запросов веб-версии с сессией человека; сессия — зашифрованной.
- Вход в банк — один поток на все банки (как у Т-Банка); при проблеме — сначала логи, потом правки.
- Сессии: Т-Банк ~10 мин + тихий вход, Сбер — жёстко час (напоминание), Озон — куки из перенаправлений; Xiaomi глушит фон (разрешения автозапуска).
- `ERR_NETWORK_ACCESS_DENIED` на мобильной сети — запрет данных приложению на телефоне.
