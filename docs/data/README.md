# Данные и разметка

Что происходит с данными внутри: категории и справочники, автоматическая разметка, сканы чеков через ФНС, импорт и экспорт, резервные копии, демо-база.

## Границы

**Сюда:** справочник категорий и групп (расходы и доходы), разметка позиций и операций (словарь, правила по продавцам, модель), «Без категории» и авторазметка, скан QR и очередь запросов в ФНС, импорт выгрузок, экспорт в таблицы, резервная копия, демо-семья.

**Не сюда:** экраны выбора категории и списков (→ [app](../app/README.md)), получение операций из банков (→ [banks](../banks/README.md)).

## Код

| Путь | Что |

| `api/src/export.mjs`, `backup.mjs` | экспорт и резервная копия (без сессий банков, токенов, паролей, приглашений, данных Telegram) |

## Документы

- `docs/fns/` — документация API ФНС (токен в `docs/fns/token/` — в git не едет).

## Важное

- Разметка решений одного человека — его данными (правила бюджета), а не общей разметкой для всех.
- База на сервере: `/opt/checker/api/data/checker.db` (WAL, время UTC); копировать через `VACUUM INTO`, не `cp`.
