# Сервер и безопасность

Где и как всё работает: серверы, выкладка, база, бот, мониторинг, производительность сервера, приватность и шифрование.

## Границы

**Сюда:** выкладка сайта, API и бота; серверы (vps2 — сайт и API, vps3 — бот); nginx и systemd; база и её копии; логи и мониторинг; производительность запросов; шифрование сессий банков, ключи, секреты; приватность данных.

**Не сюда:** что делают запросы для экранов (→ [app](../app/README.md)), банки (→ [banks](../banks/README.md)).

Отдельную сессию заводить не обязательно: задачи тут редкие и короткие — их удобно решать там, где всплыли, а сюда записывать итог.

## Код и документы

| Путь | Что |
|---|---|
| [deploy.md](deploy.md) | серверы, первичная установка, выкладка |
| `scripts/deploy_site.sh` | выкладка сайта и API одной командой (`CHECKER_HOST=vps2`, `--minor`, `--no-version`) |
| `scripts/deploy_bot.sh` | выкладка бота |
| `deploy/` | systemd-юниты, конфиг nginx |
| `api/src/server.mjs`, `db.mjs` | сервер, база, миграции |

## Важное

- Перед выкладкой — проверить синтаксис всех серверных модулей (`for f in api/src/*.mjs; do node --check "$f"; done`): один сломанный файл кладёт весь API.
- Политику Windows `RemoteDebuggingAllowed=0` не менять.
- Резервные копии — без сессий банков, токенов, паролей, приглашений, данных Telegram.
