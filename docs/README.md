## Общие правила для всех сессий

- **Один репозиторий.** Две сессии одновременно не правят один файл (чаще всего `site/m/app.js`, `api/src/server.mjs`): работаем по очереди, а для параллельной работы — отдельная рабочая копия (`git worktree`).
- **Выкладка общая.** `scripts/deploy_site.sh` выкладывает всё сразу и поднимает версию. Перед выкладкой — закоммитить своё; чужие незаконченные правки не выкладывать.
- **Доска.** Новое — карточкой в «Идеи» своего раздела; пользователь переносит в «Сделать» и «Готово», Claude — в «На проверке» после выкладки. Мелочи и баги — сразу, без карточки.
- **Договорённости** (язык ответов, дизайн как в Telegram, без личных правил в общем коде, сначала замер — потом правка, безопасность банковских данных) — в памяти Claude, подхватываются любой сессией. Знания, нужные только одному направлению, — в его папке.

## Как начать сессию

Первым сообщением — направление, его границы и просьба сначала изучить. Готовые первые сообщения — в README каждой папки, раздел «Начало сессии».
