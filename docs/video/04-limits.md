# Ролик 4. Лимиты

**Статус:** черновик (24.10.2026), запись прогона — `video/04-limits/raw/progon-1_cfr.mp4`.
**Длина:** ~30 с. **Формат и тон** — как ролик 0 ([00-overview.md](00-overview.md)).
**О чём:** лимит на группу — сколько осталось и сколько можно в день; перерасход виден сразу. Демо-база только для чтения: лист правки открывается и закрывается без сохранения.
