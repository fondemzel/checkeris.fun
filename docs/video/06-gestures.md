# Ролик 6. Жесты острова

**Статус:** черновик (24.10.2026), запись прогона — `video/06-gestures/raw/progon-1_cfr.mp4`.
**Длина:** ~20 с. **Формат и тон** — как ролик 0 ([00-overview.md](00-overview.md)).
**О чём:** три жеста на нижнем острове, которые экономят время.

## Раскадровка

| Сцена | На экране | Голос |
|---|---|---|
| 1 | Долгое нажатие на «Расход» → попап периода → палец к «Неделе»; затем снова к «Месяцу» | Долгое нажатие на кнопку острова сразу выбирает период: сегодня, неделя, месяц или год. |
| 2 | Свайп по острову — «Доход», и обратно | Свайп по острову переключает разделы. |
| 3 | «+» тянут вверх — сразу сканер | А если потянуть плюс вверх, сразу откроется сканер чеков. |
