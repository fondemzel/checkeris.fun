# Ролик 1 — голос (Яндекс SpeechKit)

Текст для синтеза: одна фраза — один файл (`01.wav`, `02.wav`…), их раскладывают по таймлайну в After Effects. Исходный текст и раскадровка — [01-expenses.md](01-expenses.md).

## Настройки

- **Голос:** женский, нейтральный. Начать с `marina` или `dasha`, амплуа `neutral`. Запасные: `alena` (neutral), `jane` (neutral). Сравнить на фразе 3 — она самая длинная и с перечислением.
- **Скорость:** `1.0`; если звучит торопливо — `0.95`. Подрезать длину проще в монтаже, чем ускорять голос.
- **Формат:** WAV (LPCM), 48 кГц, моно — без потерь для монтажа.
- **Нормализация громкости:** включить, если есть (`loudness_normalization_type: LUFS`), — у всех файлов одна громкость.

Какие амплуа есть у какого голоса, лучше сверить в SpeechKit Playground (консоль Yandex Cloud): список меняется.

## Разметка

- `+` перед ударной гласной — ударение там, где синтез может ошибиться: `Ч+екер`, `расх+од`, `маркетпл+ейсов`.
- `sil<[300]>` — пауза в миллисекундах: между частями фразы, где на экране что-то происходит.
- Кавычки «…» в синтез не отдаём: голос их не читает, а интонацию они иногда ломают.

## Фразы

**01** — 0–6 с, кольцо заливается
```
Экран расх+ода показывает все траты за выбранный период. sil<[250]> Кольцо делит их на группы: питание, жильё, транспорт и другие.
```

**02** — 6–16 с, нажатие на группу
```
Нажатие на группу открывает её кольцо: sil<[200]> категории группы и их доли.
```

**03** — 16–26 с, список покупок категории
```
Нажатие на категорию открывает список покупок. sil<[300]> Покупки попадают сюда из чеков, банковских приложений и маркетпл+ейсов, их можно добавить и вручную. sil<[250]> Каждая строка — отдельная покупка с ценой и датой.
```

**04** — 26–36 с, свайп месяцев
```
Свайп влево или вправо переключает период. sil<[250]> Суммы и доли пересчитываются сразу.
```

**05** — 36–45 с, долгое нажатие на «Расход»
```
Долгое нажатие на кнопку расх+ода открывает выбор периода: sil<[200]> сегодня, неделя, месяц или год.
```

**06** — 45–58 с, режим списка
```
Кольцо можно переключить на список. sil<[250]> Здесь все покупки собраны в разделы по категориям. sil<[250]> Раздел раскрывается нажатием.
```

**07** — 58–66 с, сортировка
```
Сортировка: sil<[150]> по названию, по сумме или по дате — sil<[150]> тогда разделы становятся днями.
```

**08** — 66–74 с, фильтр
```
Фильтр оставляет покупки из одного источника: sil<[150]> чеки, банк, маркетпл+ейсы или ручные записи, sil<[150]> или только нужные группы.
```

**09** — 74–88 с, поиск и карточка
```
Поиск находит покупки по названию за выбранный период. sil<[300]> Карточка покупки содержит детальную информацию: дату, продавца, категорию и комментарий.
```

**10** — 88–100 с, лимит
```
Если для группы задан лимит, sil<[150]> под кольцом видно, сколько потрачено, сколько осталось и сколько можно тратить в день до конца месяца.
```

**11** — 100–107 с, заставка
```
Ч+екер. sil<[300]> Учёт расходов по чекам и операциям банков.
```

## Отличия от текста раскадровки

- «Экран „Расход“» → «Экран расхода», «долгое нажатие на „Расход“» → «на кнопку расхода»: название в кавычках голос произносит как обычное слово, и на слух непонятно, что это кнопка.
- Фильтр: «— чеки, банк… —» → двоеточие и запятые: тире в середине фразы синтез читает без нужной паузы.
