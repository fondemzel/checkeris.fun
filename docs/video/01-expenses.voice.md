# Ролик 1 — голос (Fish Audio Drama 3)

Текст для синтеза — одним куском, по реплике на строку (ниже). Исходный текст и раскадровка — [01-expenses.md](01-expenses.md). Файлы — в [video/01-expenses/voice](../../video/README.md).

Голос — тот же референс, что у ролика 0 (женский, русскоязычный): ролики одной серии звучат одним голосом. 3–4 дубля, WAV 48 кГц.

## Разметка

Как у ролика 0 ([00-overview.voice.md](00-overview.voice.md)):

- Каждая реплика — своя строка с `<|speaker:0|>`; паузу между строками модель делает сама.
- Без тегов пауз (`[pause]`, `[short pause]`): с ними модель выбрасывает куски текста.
- Указание манеры — коротко и один раз, в первой строке.
- `<emphasis>…</emphasis>` — по одному на реплику.
- Ударения проверить на слух: «маркетплейсов» (маркетпл**е**йсов), «лимит» (лим**и**т), «Чекер» (Ч**е**кер).

## Текст целиком

```
<|speaker:0|> [bright upbeat female narrator, warm, light smile, natural pace] Экран расхода показывает все траты за выбранный период. Кольцо делит их на группы: питание, жильё, транспорт и другие.
<|speaker:0|> Нажатие на группу открывает её кольцо: категории группы и их доли.
<|speaker:0|> Нажатие на категорию открывает список покупок. Покупки попадают сюда из чеков, банковских приложений и маркетплейсов, их можно добавить и вручную. Каждая строка — <emphasis>отдельная покупка</emphasis> с ценой и датой.
<|speaker:0|> Свайп влево или вправо переключает период. Суммы и доли пересчитываются <emphasis>сразу</emphasis>.
<|speaker:0|> <emphasis>Долгое нажатие</emphasis> на кнопку расхода открывает выбор периода: сегодня, неделя, месяц или год.
<|speaker:0|> Кольцо можно переключить на список. Здесь все покупки собраны в разделы по категориям. Раздел раскрывается нажатием.
<|speaker:0|> Сортировка: по названию, по сумме или по дате, тогда разделы становятся днями.
<|speaker:0|> Фильтр оставляет только нужное: чеки, банк, маркетплейсы или ручные записи, и любые группы. Можно выбрать <emphasis>сразу несколько</emphasis>.
<|speaker:0|> Поиск находит покупки по названию за выбранный период. Карточка покупки содержит детальную информацию: дату, продавца, категорию и <emphasis>комментарий</emphasis>.
<|speaker:0|> Если для группы задан лимит, под кольцом видно, сколько потрачено, сколько осталось и <emphasis>сколько можно тратить в день</emphasis> до конца месяца.
<|speaker:0|> Чекер. Учёт расходов по чекам и операциям банков.
```

| Строка | Сцена |
|---|---|
| 1 | кольцо заливается |
| 2 | нажатие на «Питание» |
| 3 | «Еда» — список покупок |
| 4 | свайп на ноябрь и обратно |
| 5 | долгое нажатие на «Расход», «Год» |
| 6 | список, «Рестораны и кафе» |
| 7 | сортировка «По дате» |
| 8 | фильтр «Чеки» |
| 9 | поиск «икра», карточка с комментарием |
| 10 | лимит «Транспорта» |
| 11 | заставка |

## Отличия от текста раскадровки

- «Экран „Расход“» → «Экран расхода», «долгое нажатие на „Расход“» → «на кнопку расхода»: название в кавычках голос произносит как обычное слово, и на слух непонятно, что это кнопка.
- Тире внутри фраз (сортировка, фильтр) заменены запятыми и точкой: на тире синтез не делает паузу. Тире-связка «Каждая строка — отдельная покупка» оставлена.
