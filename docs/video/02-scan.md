# Ролик 2. Скан чека за пару секунд

**Статус:** черновик (24.10.2026), запись прогона — `video/02-scan/raw/progon-1_cfr.mp4`.
**Длина:** ~20 с. **Формат и тон** — как ролик 0 ([00-overview.md](00-overview.md)): тёмная тема, демо-семья, голос не пересказывает кадр.
**О чём:** главный способ добавить трату — свайп «+» вверх, QR с чека, и покупки уже по категориям.

## Раскадровка

| Сцена | На экране | Голос |
|---|---|---|
| 1 | Май, кольцо; выделение на «+»; палец тянет «+» вверх — из кнопки растёт полоса со значком сканера | Чтобы добавить трату с чеком, потяните плюс вверх. |
| 2 | Сканер: рамка; выделение на «Ввести строку из QR вручную» | Сканер найдёт QR-код внизу чека. Если код не читается, его строку можно ввести вручную. |
| 3 | Код пойман: в рамке QR, по рамке бегут утолщения, «Ждём ответа ФНС…» | Чекер запрашивает чек в налоговой: обычно это пара секунд. |
| 4 | «Добавлено»: шесть позиций; выделение на корме («Питомцы»), на порошке («Хозтовары») | Покупки сразу разложены по категориям: молоко в продукты, корм питомцам, порошок в хозтовары. |
