# Ролик 1. Экран «Расход»

**Длина:** ~107 секунд (съёмка с `--pace 2`). **Формат:** вертикальный, запись экрана телефона 1080×2400.
**О чём:** как устроен экран расходов — группы, категории, откуда берутся покупки, периоды, режим списка (разделы, сортировка, фильтр), поиск, лимиты.
**Тон:** нейтральный, технический: что на экране и что делает действие. Без вопросов к зрителю, восклицаний и слогана.

## Подготовка

Съёмка — по рецепту [README.md](README.md): Chrome на телефоне, демо-семья, «сегодня» — 18 декабря.
Сценарий действий — [01-expenses.film.mjs](01-expenses.film.mjs); время ниже — в готовом ролике (отметки сценария × 2).

## Раскадровка

| Время | На экране | Голос за кадром |
|---|---|---|
| 0–6 с | «Расход» за декабрь, кольцо заливается | Экран «Расход». Здесь показаны все траты за период. Категории трат и группы собраны в наглядное кольцо. |
| 6–16 с | Нажатие на «Питание» → кольцо группы: еда, кафе, алкоголь | Нажатие на группу открывает её кольцо: категории группы и их доли. |
| 16–26 с | Нажатие на «Еду» → список покупок, раскрыт раздел | Нажатие на категорию — список покупок. Покупки попадают сюда из чеков, банковских приложений и маркетплейсов, их можно добавить и вручную. Каждая строка — отдельная покупка с ценой и датой. |
| 26–36 с | Назад к кольцу «Питания», свайп на ноябрь и обратно | Свайп влево или вправо переключает период. Суммы и доли пересчитываются сразу. |
| 36–45 с | Долгое нажатие на «Расход» → попап периода, выбор «Год» | Долгое нажатие на «Расход» открывает выбор периода: сегодня, неделя, месяц или год. |
| 45–58 с | Кнопка вида → список по категориям, раскрыт раздел «Рестораны и кафе» | Кнопка справа переключает кольцо на список. В списке покупки собраны в разделы по категориям, у раздела — число покупок и сумма. Раздел раскрывается нажатием. |
| 58–66 с | Сортировка → лист снизу → «По дате»: разделы по дням | Сортировка меняет порядок: по дате — тогда разделы становятся днями, по названию или по сумме. |
| 66–74 с | Фильтр → лист снизу → «Только чеки» | Фильтр оставляет покупки из одного источника: чеки, банк, маркетплейсы или ручные записи. |
| 74–88 с | Поиск «икра», карточка покупки с комментарием | Поиск находит покупки по названию за выбранный период. В карточке покупки — дата, продавец, категория и комментарий. |
| 88–100 с | Кольцо «Питания» за декабрь, карточка лимита | Если для группы задан лимит, под кольцом видно, сколько потрачено, сколько осталось и сколько можно тратить в день до конца месяца. |
| 100–107 с | Заставка: значок, название, адрес сайта | Чекер. Учёт расходов по чекам и операциям банков. |

## Текст для диктора целиком

> Экран «Расход». Здесь показаны все траты за период. Категории трат и группы собраны в наглядное кольцо.
>
> Нажатие на группу открывает её кольцо: категории группы и их доли.
>
> Нажатие на категорию — список покупок. Покупки попадают сюда из чеков, банковских приложений и маркетплейсов, их можно добавить и вручную. Каждая строка — отдельная покупка с ценой и датой.
>
> Свайп влево или вправо переключает период. Суммы и доли пересчитываются сразу.
>
> Долгое нажатие на «Расход» открывает выбор периода: сегодня, неделя, месяц или год.
>
> Кнопка справа переключает кольцо на список. В списке покупки собраны в разделы по категориям, у раздела — число покупок и сумма. Раздел раскрывается нажатием.
>
> Сортировка меняет порядок: по дате — тогда разделы становятся днями, по названию или по сумме.
>
> Фильтр оставляет покупки из одного источника: чеки, банк, маркетплейсы или ручные записи.
>
> Поиск находит покупки по названию за выбранный период. В карточке покупки — дата, продавец, категория и комментарий.
>
> Если для группы задан лимит, под кольцом видно, сколько потрачено, сколько осталось и сколько можно тратить в день до конца месяца.
>
> Чекер. Учёт расходов по чекам и операциям банков.

178 слов — около 81 секунды при спокойном темпе. Остальное — паузы на действия: голос начинает фразу, когда действие уже видно.

## Открытые вопросы

- Голос и музыка — общее решение на серию (карточка «Голос и музыка для роликов»).
- Длина больше минуты: для Shorts и Клипов (до 60 с) — снимать с `--pace 1.5` (~80 с) не хватит; либо делить на два ролика (кольцо и список), либо этот — для раздела «Как пользоваться», а для соцсетей — укороченный.
