# checkeris.fun

Учёт личных расходов по чекам из приложения «Проверка чеков» (ФНС): выгрузка чеков
раскладывается в базу, кабинет показывает чеки и товарные позиции в табличном виде.

## Структура

| Каталог | Что внутри |
| --- | --- |
| `api/` | Импорт выгрузок ФНС в SQLite и HTTP API кабинета (без внешних зависимостей, Node 22.5+) |
| `site/` | Лендинг и кабинет `/cabinet` — статика, без сборщика |
| `deploy/` | systemd-юнит и конфиг nginx для VPS |
| `scripts/` | Выкладка на сервер |
| `docs/` | [Кабинет](docs/cabinet.md), [Деплой](docs/deploy.md) |
| `client/` | Задел под мобильный клиент и ботов |

## Запуск локально

```bash
node api/src/import.mjs      # выгрузки из api/data/fns_out/*.json → api/data/checker.db
node api/src/server.mjs      # http://localhost:8787/cabinet
```

Выгрузки ФНС и собранная база в репозиторий не попадают — это личные данные, см. `.gitignore`.
